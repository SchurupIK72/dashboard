# Small-Fix Statement Template

Короткая постановка фикс-задачи, собранная из диалога. Режим диалога (Default или Plan) не влияет на применимость шаблона.

```markdown
Симптом:
{что сейчас не так}

Ожидаемое поведение:
{что должно быть после фикса}

Границы изменения:
- Можно трогать: {files/modules}
- Не трогать: {out-of-scope}

Проверка готовности:
{команда, тест или ручная проверка}

Пояснение числа файлов (если файлов больше warning-порога, по умолчанию 3):
{почему это один локальный обратимый фикс}
```
