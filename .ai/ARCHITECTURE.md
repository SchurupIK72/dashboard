# Архитектура Dashboard

## Назначение
Веб-дашборд для совместного путешествия по Вьетнаму (2 компании, 3 пользователя): список покупок, дела, учёт расходов со справедливым делением по чекам и вычетом личных трат (корм собаки), погода, курсы RUB/USD к VND и BTC/ETH с графиками. Python/FastAPI + SQLite + Jinja2/HTMX, запуск на VPS или локально в Docker.

## Точка входа
Заполняется после первого релиза (планируется src/dashboard/main.py, FastAPI).

## Структура модулей
Заполняется по мере развития проекта. Планируемые домены: покупки, дела, расходы (разделение по чекам), погода, курсы валют/крипты, пользователи (3 учётные записи, полные права).

## Ключевые паттерны
Заполняется по мере развития проекта.

## Потоки данных
Заполняется по мере развития проекта. Внешние источники: погода и курсы — по расписанию в кэш SQLite.
