### Solution Summary
Frozen dataclass Settings (secret_key and user passwords have repr=False) with properties database_path (Path of the part after sqlite:///) and timezone (ZoneInfo). load_settings(environ, env_file=None) merges the .env values under the environment mapping, so the environment wins. load_settings_from_environment() uses os.environ and ./.env. The .env parser is stdlib only: KEY=VALUE lines, # comments, blank lines, matching quotes stripped, lines without "=" ignored, missing file means no values. DATABASE_URL, SECRET_KEY and DASHBOARD_USERS are required; empty or missing gives an error naming the variable. Defaults apply to TZ, COOKIE_SECURE, WEATHER_CITY and the two refresh variables; an empty value is invalid. Errors never echo values. Validation: SECRET_KEY must be at least 32 characters and not change-me; DATABASE_URL needs the sqlite:/// prefix and a non-blank path; TZ must be an existing IANA name (ZoneInfoNotFoundError, ValueError and OSError are caught); minutes are strict ASCII digits from 1 to 1440; COOKIE_SECURE is true or false, case-insensitive; DASHBOARD_USERS is JSON with exactly 3 objects, non-empty string login, password and company, unique logins, and exactly 2 distinct companies. No public-contract change outside the file. No comments in the code.
