### Solution Summary
Both files existed already (staged, `A`) and matched R4 and the shared contract, so I verified them and edited nothing. `connect` creates the parent directory, opens a new connection per call with `row_factory=sqlite3.Row` and `check_same_thread=False`, and sets the three PRAGMAs. `initialize_schema` reads the packaged `schema.sql` through `importlib.resources` and runs `executescript`, then commits. Every statement is `IF NOT EXISTS`, so repeated calls are safe. There are no spec references in comments, and the only docstrings are one sentence on public functions. Deviations from the package's design guidance:
- The function is named `initialize_schema`, not `apply_schema`.
- `open_database` was not added (it was optional).
- `connect` takes `Path`, not `str | os.PathLike`.
- `schema.sql` declares `app_meta` instead of being empty.
