item_text: [R3, R47] Реализовать `Settings` с чтением env и `.env`, значениями по умолчанию, валидацией и ошибкой с именем переменной.

requirements (copy of spec, the oracle):
- R3: Конфигурация читается из переменных окружения и файла `.env`: `DATABASE_URL`, `SECRET_KEY`, `TZ`, `DASHBOARD_USERS`, `COOKIE_SECURE`, `WEATHER_CITY`, `WEATHER_REFRESH_MINUTES`, `RATES_REFRESH_MINUTES`; значения по умолчанию: `TZ=Asia/Ho_Chi_Minh`, `COOKIE_SECURE=false`, `WEATHER_CITY=Ho Chi Minh City`, `WEATHER_REFRESH_MINUTES=30`, `RATES_REFRESH_MINUTES=15`; значения из окружения приоритетнее `.env`. DATABASE_URL, SECRET_KEY, DASHBOARD_USERS have no defaults (missing → error naming the variable).
- R47: `SECRET_KEY` — не короче 32 символов и не равен `change-me`; `DATABASE_URL` — вида `sqlite:///<путь>`; `TZ` — существующее имя IANA; `WEATHER_REFRESH_MINUTES` и `RATES_REFRESH_MINUTES` — целые от 1 до 1440; `COOKIE_SECURE` — `true` или `false` без учёта регистра; `DASHBOARD_USERS` — JSON по формату Q13; при нарушении приложение не стартует, сообщение называет переменную.
- Q13: DASHBOARD_USERS — JSON-массив из трёх объектов `{"login","password","company"}` (non-empty strings, unique logins); значение `company` — название компании, ровно два различных названия. Settings enforces all of this and names `DASHBOARD_USERS` on violation.
- Verification (what the acceptance tester will check): unit tests of `Settings`: reading from env and from `.env`, defaults when absent, env priority over `.env`; for each variable an invalid value → error containing its name; boundary 32 vs 31 chars of SECRET_KEY; `change-me` rejected.

design guidance:
- Module `src/dashboard/settings.py`. Public: frozen dataclass `Settings`, error class `SettingsError(ValueError)` (message contains the variable name), a loader that takes an explicit environment mapping and an optional `.env` path (testable without touching os.environ), and a convenience loader reading `os.environ` and `.env` from the current directory. `.env` is parsed in pure stdlib (KEY=VALUE lines, `#` comments, blank lines, optional surrounding single/double quotes on the value; invalid lines ignored or error — your choice, keep simple). A user record type for DASHBOARD_USERS entries (login, password, company). Expose `database_path` (pathlib.Path): `sqlite:///data/x.db` → relative `data/x.db`; `sqlite:////abs/x.db` → `/abs/x.db`; `sqlite:///C:/x/y.db` → `C:/x/y.db`; and `timezone` (zoneinfo.ZoneInfo) derived from TZ.
- Empty-string env values count as "set but invalid" for required vars (error naming the variable); for vars with defaults an empty value is also invalid except WEATHER_CITY must be non-empty too.
- Passwords and SECRET_KEY must never appear in `repr`/error messages (use `field(repr=False)` and never echo values in errors).
- No `Any`, full type hints, no comments except `D##` refs, one-sentence docstrings on public API at most.
